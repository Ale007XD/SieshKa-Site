# 🍕 SieshKa - Сайт для Заказа Еды

Привет! 👋 Это инструкция как запустить сайт для ресторана "Сиешка". Не бойся, всё просто! Просто следуй шагам ниже.

**Последнее обновление:** 3 апреля 2026 ✅ **Checkout восстановлен, YooKassa схема готова (85%)**

---

## 🎯 Что это такое?

Это веб-сайт где клиенты могут:
- 🍔 Смотреть меню с учетом времени доступности
- 🛒 Добавлять еду в корзину
- 📱 Оформлять заказы **наличными** ✅ или **YooKassa** ⏳
- 👨‍🍳 Админы управляют через панель `/admin`

---

## 📦 Что тебе понадобится

1. 🐳 **Docker** - коробка для сайта
2. 📁 **Файлы проекта** - папка `SieshKa-Site-v3.1-rc1`
3. 🔑 **SSL сертификаты** для https:// (получим вместе)

```bash
sudo apt update && sudo apt install apache2-utils -y
```

---

## 🚀 Быстрый старт (6 шагов)

### Шаг 1: Открой папку
```bash
cd SieshKa-Site-v3.1-rc1
```

### Шаг 2: Настройки
```bash
cp .env.example .env
nano .env
```
